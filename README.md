## Project Overview

This repository contains implementations of Machine Learning and Deep Learning algorithms developed as part of the Azure AIML Assignment.

---

## Task 1: Linear Regression and Logistic Regression

- MinMaxScaler implemented from scratch to scale features.
- Linear Regression from scratch using gradient descent to predict house prices, showing convergence with/without scaling.
- Logistic Regression from scratch to classify price trends (Up/Down) with loss curve plotting.
- Performance metrics (Accuracy, Precision, Recall, F1, Confusion Matrix) calculated from scratch.

---

## Task 2: Machine Learning Models

- Classification models (Decision Tree, Random Forest, SVM) evaluated under imbalanced and balanced scenarios.
- Manual oversampling algorithm to balance credit card fraud datasets.
- Q-Learning Fraud Patrol agent path-finding in a grid layout.
- Conceptual NumPy implementations of an LSTM Cell (forget, input, output gates) and Q-Network forward pass.

---

## Task 3: Deep Learning and Computer Vision

- Convolutional Neural Network (CNN) feature extraction implemented from scratch in NumPy.
- Noise-resilient synthetic handwritten digit sketch canvas generator.
- 6 hand-crafted kernels (Vertical/Horizontal Edge, Diagonals, Spot, Smooth) doing conv, ReLU, and Max Pool.
- Heatmap visualization of filters stage-by-stage and digit classification confusion matrix.

---

## Task 4: Chatbot using RNN and LSTM

- Mood-Aware Chatbot analyzing user statements via a sentiment lexicon (negation and amplifier aware).
- Exponentially smoothed Mood Tracker dynamically shifting reply states (Cheerful, Neutral, Concerned).
- Live ASCII mood meter display and turn-by-turn emotion history chart.
